Trazer as cifras dos sites

Clique em ⚡ Buscar cifras automaticamente. As músicas que você adiciona já são buscadas sozinhas.

  • Link de qualquer site: a cifra é buscada direto do link. Se não der certo, a música é procurada pelo nome.
  • CifraClub bloqueia buscas automáticas, então a música é procurada pelo nome em outros sites.
  • Busca pelo nome: pesquisa ao mesmo tempo no Músicas para Missa, no Cifras.com.br e na web. Só vale cifra com acordes. Confira a versão clicando na música, na lista do Início.

🔎 Quer a versão exata do CifraClub (ou de outro site)? Use o favorito
  1. Só na primeira vez: arraste este botão para a barra de favoritos: 🎵 Enviar cifra
  2. Clique no botão do site abaixo. Ele abre uma das cifras.
  3. Na página que abrir, clique no favorito 🎵 Enviar cifra. As cifras daquele site chegam aqui de uma vez (inclusive substituindo as que vieram do Músicas para Missa).
Como criar o favorito no celular ou se arrastar não funcionar
  1. Toque em Copiar código do favorito.
  2. Crie um favorito qualquer no navegador (ex.: desta página), edite, troque o nome para Enviar cifra e cole o código no lugar do endereço.
  3. No site da cifra, toque na barra de endereço, digite Enviar cifra e toque no favorito.

Também dá para colar a cifra direto no editor: na lista do Início, clique na música.
