3. Trazer as cifras dos sites

⚡ Músicas para Missa: automático. A cifra vem sozinha quando você adiciona o link (ou clique no botão ⚡ abaixo).

🔎 CifraClub: pelo favorito. O CifraClub bloqueia qualquer servidor e só abre para navegadores de pessoas, então a busca é feita por um botão nos favoritos, que busca de uma vez todas as cifras que faltam do site (também serve para outros sites de cifra):

  1. Só na primeira vez: arraste este botão para a barra de favoritos: 🎵 Enviar cifra (no celular, veja as instruções abaixo)
  2. Clique no botão do site abaixo. Ele abre uma das cifras que faltam.
  3. Na página que abrir, clique no favorito 🎵 Enviar cifra. Todas as cifras daquele site chegam aqui de uma vez.

Como criar o favorito no celular ou se arrastar não funcionar
  1. Toque em Copiar código do favorito.
  2. Crie um favorito qualquer no navegador (ex.: desta página), edite, troque o nome para Enviar cifra e cole o código no lugar do endereço.
  3. No site da cifra, toque na barra de endereço, digite Enviar cifra e toque no favorito.

Instalou o favorito antes? Troque pelo novo (arraste de novo) para buscar todas de uma vez; o antigo continua trazendo uma cifra por vez. Também dá para colar a cifra direto no editor da seção 4.

4. Revisar e editar

Abra uma música, altere o que precisar e clique em Salvar alterações. Mantenha os acordes na linha de cima da letra, com espaços para alinhar.

5. Baixar

Nenhuma cifra pronta ainda. Traga ou cole as cifras acima.
